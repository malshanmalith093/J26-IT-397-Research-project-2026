#  J26-IT-397 Research-project-2026 Malabe 

<h2>Overview  </h2>

This is a research under SDG – 4, quality education category from sustainability development goals. With 
implementing system of “AI-Powered Personalized E-Learning System for Student Progress Tracking and 
Engagement Enhancement” is aimed to early identification and avoidance of academic failures of 
university students. Below 4 components are implemented for the fulfill the given objectives. 

1. Predictive academic risk assessment – Identification and early alerts of academic declines.
 
2. Adaptive learning behavior profiling – Learner profile for users based on engagement patterns, 
study hours, academic performance.
 
4. Personalized learning path optimization – Prioritization of the tasks based on weakness score of 
each academic module.
 
5. Educational resource recommendation – Academic resource recommendation based on learner 
profile
